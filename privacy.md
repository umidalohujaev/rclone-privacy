# Privacy Policy

Last updated: October 14, 2026

This application is a personal tool used by its owner, Umid Alohujaev, to synchronize the owner's own files between the owner's cloud drive account and the owner's own servers, using the open-source rclone software. It is not offered to the public and has no other users.

## Data accessed

The application requests access to files in the owner's own cloud drive account. It uses this access only to list, copy, back up and synchronize those files.

## How data is used and shared

Data is used solely for the owner's personal file synchronization. It is not sold, shared with, or disclosed to any third party, and it is not used for advertising or analytics. The use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

## Storage and security

Files are copied only to servers controlled by the owner. The authorization token is stored in a configuration file on the owner's own server and is not transmitted to anyone else.

## Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions
